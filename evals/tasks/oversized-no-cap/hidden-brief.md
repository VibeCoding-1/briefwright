# Hidden brief: the oversized "no cap" ask

You want a repository of agent skills, subagents, hooks and small tools, assembled from the best
open-source pieces, that measurably beats the large public collections.

What you mean, when asked:
- Where it runs: Claude Code, launched from the command line on your laptop (a personal machine), at
  the harness's default effort. You name no model; if asked for one, say the run may choose.
- "No cap on time or tokens" means: do not stop early to save tokens. The run itself is one working day
  at most; you check in now and then (attended).
- If the assistant proposes a first working version plus later increments, you agree, and this prompt
  covers the first version: a repository with a README, at least five skills and two hooks, an install
  script, and a comparison table against two public collections.
- Evidence: for this first version you accept the cheaper evidence (critic seats that read and install
  the pieces); no headless benchmark yet.
- Licences: only permissively licensed pieces (MIT, Apache-2.0, BSD), each with its notice.
- Working folder: the empty folder this session runs in; git is initialised; there is no remote.
- Anything else: you don't know; accept the recommendation.
